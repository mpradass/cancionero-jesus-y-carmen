# Cancionero de boda · Jesús + Carmen

Cancionero digital de la boda del 27 de noviembre de 2026. Conserva las tres páginas del PDF original y las presenta en este orden: «El Dios que adoramos», «Sublime gracia» y, al final, el menú.

## Activar GitHub Pages

En el repositorio, abre **Settings → Pages** y, en **Build and deployment**, selecciona **GitHub Actions** como fuente. Después, en **Actions**, comprueba el flujo «Publicar cancionero en GitHub Pages». Al terminar, la dirección será:

https://mpradass.github.io/cancionero-jesus-y-carmen/

El flujo vuelve a publicar automáticamente el sitio cuando se actualiza la rama main.
